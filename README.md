# EfeitoIma
Um estudo de futebol sobre como poderemos mensurar o efeito de um jogador sem a bola
Essa métrica será abordada, de maneira mais detalhada, a partir de um dashboard individualizado para cada jogador mensurado todas as variáveis possíveis para
unificar em uma única métrica o valor de chance de gol que a movimentação daquele determinado jogador consegue aumentar para si mesmo e para a equipe dependendo de qual espaço do campo essa movimentação ocorre
